# Quick Push Guide

## 1. Open terminal in this project folder

```bash
cd face-emotion-recognition-github
```

## 2. Initialize git

```bash
git init
git add .
git commit -m "Initial commit - face emotion recognition project"
```

## 3. Create a new empty GitHub repository
Example name: `face-emotion-recognition`

## 4. Connect local repo to GitHub

```bash
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/face-emotion-recognition.git
git push -u origin main
```
